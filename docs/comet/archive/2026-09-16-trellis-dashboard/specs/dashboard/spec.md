# Trellis Dashboard 完整目标规格

本规格描述完整的本地只读 Dashboard，包含任务、规范和工作记录。验收条目集中列在 brief.md 的 A1–A10，A3、A4、A6 覆盖任务面板与阅读区域的屏效及独立滚动；其余数据、安全、命令和交付要求保持不变。

## R1：独立命令与项目发现

- 提供独立命令 `trellis-dashboard`；不占用或替换官方 `trellis` 命令。
- 构建产物包含服务端与前端静态资产。用户将本地包安装一次后，在任意已有 `.trellis` 的项目运行命令即可打开浏览器面板，无须在目标项目安装依赖或增加配置。
- 默认从 cwd 向上寻找最近的 `.trellis` 项目；支持显式项目路径，支持含空格/中文的路径。
- 支持帮助、端口参数和不自动打开浏览器的参数。终端打印所选项目与可访问的本地 URL。
- 默认仅使用回环地址。端口占用、无权限、目录不存在或没有 `.trellis` 均给出原因和修复提示；不得静默服务错误项目。
- 停止命令后释放监听端口与计时/监听资源。打开浏览器失败时保留可用服务并提示 URL，不把服务启动误判为失败。
- npm 远程发布不属于本需求；README 必须区分“本地安装可用”与“将来发布后可 npx 使用”，不能声称包已经发布。

## R2：任务模型、状态与归档

- 数据来自 `.trellis/tasks` 的活动任务，以及 `tasks/archive/YYYY-MM/` 下的归档任务。识别以 `task.json` 为元数据的目录，不依赖任务目录名等于 id/name。
- title、description、status、priority、creator、assignee、createdAt/completedAt、dev_type、scope、package、branch/base_branch、worktree_path、commit、pr_url、parent/children、subtasks、relatedFiles、notes、meta 均按真实内容展示或在原始数据中可查看。
- 已知状态 planning、in_progress、completed 以中文呈现并保留原值；未知自定义状态不得丢失任务或映射成完成。归档由路径及元数据共同呈现，不假设所有 completed 目录都已归档。
- 空数组、null、缺失可选字段合法。没有 title 时可回退 name/id/目录名，并明确实际来源；不填造优先级、负责人或日期。
- parent/children 是任务关系，不自动绘制成依赖图；未解析的关联显示原值而不访问任意路径。
- 提供任务统计、看板/列表、关键词搜索（至少标题、名称、描述）、状态/优先级/负责人筛选与归档视图。组合筛选后数字与展示集合一致，并有清除筛选入口。
- 样例项目的六个任务是真实只读冒烟数据，不作为硬编码或被提交进仓库的演示数据。
- 任务面板也使用视口内固定框架，压缩标题和统计卡片的装饰性占高；导航、标题、统计、搜索/筛选及范围/视图切换保持可达，看板/列表使用剩余可用高度，不把任务数量转化为整个右侧页面的高度。
- 看板每列的卡片列表是独立纵向滚动容器，列头固定。滚动某列不改变旁列位置；到达边界后不会继续滚动整页。窄屏时各列可在看板内部横向浏览，不让页面横向溢出。
- 列表模式在独立容器内滚动数据，表头保持可见；横向列内容的滚动限制在表格区域。切换视图、筛选和归档后的统计仍与实际集合一致。
- 窄屏保留搜索和排序入口，完整状态/优先级/负责人筛选可通过显式按钮按需展开和关闭，不因紧凑布局丢失功能。空态与错误反馈仍在受限内容区域可见。

## R3：任务详情与产物

- 从列表/卡片进入详情，查看完整元数据与该任务现有文件。
- 支持 PRD、design.md、implement.md、research Markdown，以及 JSON/JSONL 上下文清单的阅读。
- 不要求所有任务都有 design.md 或 implement.md；不存在时显示未提供/省略相应入口，不影响其他内容。
- JSONL 按行解析并展示 file/reason 等真实字段；模板 `_example` 不当成有效上下文条目；损坏行提示位置，其他合法行仍可读。
- 上下文清单只列出引用关系，不执行脚本，不自动读取清单指向的项目源码或 `.trellis` 外文件。
- Markdown 支持标题、列表、表格、代码、复选框等常见内容；原始 HTML 和危险 URL 不执行。
- 允许的内部文档链接只在受限目录中导航；外部链接显式点击才可打开，并与面板隔离。外部图片等不应在打开本地私有文档时自动发起请求。
- 有意义的内容上限须可见：超限文件提示大小/限制，不静默截断为完整内容，也不耗尽服务内存。
- 详情弹层接近可用视口，默认以文档阅读为主体。头部只保留必要的标题、状态与操作；完整描述、任务关系、备注等次要信息可在独立信息页签查看，不能因压缩布局丢失原信息。
- 产物目录、Markdown/JSON/JSONL 正文各自拥有受限的滚动区域；弹层标题、产物页签和文档路径工具栏保持固定。滚动到底部不继续带动背景页面。
- 默认文档阅读状态下，1440×900 视口的正文滚动容器高度至少为 630px，390×844 视口至少为 422px；测量不包含文档工具栏，不以文档内容总高度充当视窗高度。长任务说明通过信息页签呈现，不无限增高头部。

## R4：可解释的进度

- 若存在 implement.md，进度可由非代码块内 Markdown 复选框的已选/总数计算，显示为“执行计划 X/Y”并给出来源。
- 没有 implement.md 或复选框总数为零时，显示未提供可计算进度，不显示伪造百分比。
- 勾选比例不是测试通过率，不改变 task.json.status，也不推断 Verify 阶段、批次完成或正式验收结论。
- `in_progress` 可涵盖实现、检查和收尾，不能强制归为其中一个阶段。
- 持久化会话指针不是进程存活证据；首版不提供实时 Agent 运行状态或控制。

## R5：规范与工作记录

- 规范页按 `.trellis/spec/` 的真实相对目录组织 Markdown；兼容旧式 frontend/guides 和多包、多层结构，不硬编码目录深度。
- 能查看 index.md 及其邻近规范，通过受限内部链接导航；保持原文件为唯一数据源。
- 工作记录页按 `.trellis/workspace/<developer>/` 聚合 index.md 与 journal-N.md，并可查看根 workspace 索引。
- 开发者标识、文档路径与内容按实际存在值呈现；没有日志时给空态。
- 日志是历史文档，不是实时对话，也不据此推断在线人员/运行进程。
- 两个文档页使用紧凑标题区，标题右侧安排当前模块的文件搜索工具，取消与阅读无关的大块留白；目录区不重复占用一行搜索空间。
- 桌面布局在可用视口内固定全局导航、模块标题和文档工具栏。左侧目录列表与右侧正文分别独立滚动，任一区域滚轮不改变另一区域或整个页面的位置；滚动到边界也不向页面传递。
- 默认阅读状态下，1440×900 正文滚动容器高度至少为 630px。390×844 下目录默认收起，提供可访问的目录展开/关闭入口，选择文档后回到阅读；正文视窗至少为 422px，不出现页面级横向溢出。
- 所有三个模块均为首版正式功能，不保留尚未实现的操作入口。

## R6：刷新、缺失与错误

- 面板在服务运行期间感知外部文件新增、更新、删除，五秒内同步或通过手动刷新立即更新。
- 加载、刷新、空列表、无匹配筛选、没有可选文档及读取失败有不同且明确的反馈。
- 损坏 task.json 隔离到对应目录并报告原因；不导致全部合法任务不可用。
- 文件读取期间被删除、可选目录缺失、JSONL 个别行损坏、未知字段/状态不导致进程崩溃。
- `.trellis` 整体消失或访问失败时显示不可用状态；不把保留的旧快照称为最新数据。
- 不确定错误不得悄悄转换为空项目成功状态；反馈中不泄漏无关文件内容。
- 阅读区域的自动刷新不得无故将当前文档滚动位置重置到顶部；内部锚点导航只移动正文容器，不拖动固定框架。更换文档时可从新文档顶部或指定锚点开始。
- 任务面板在视图和筛选条件未变化时自动刷新，不应无故重置卡片列、看板横向位置或表格的滚动位置；显式改变视图/筛选时允许定位新的结果集合。

## R7：本地数据与安全边界

- 默认只监听回环地址，拒绝面向公网/局域网的默认监听；无云端数据存储、遥测和上传。
- 用户 Markdown、JSON、JSONL、文件名和链接均视为不可信数据；不执行其 HTML/JS、hooks、Python 或 shell。
- 文件 API 仅允许受限 `.trellis` 内容类型与目录；真实路径检查阻止目录穿越、编码绕过、绝对路径注入和越界符号链接。
- 不提供系统文件、任意源码、`.env`、脚本、运行时私有文件的通用读取接口。
- 不主动加载来源文档的远程资源；目标数据不复制到发布包或作为内置演示。
- 无业务写 API，不修改目标项目 `.trellis`、package.json 或 Git 状态，运行前后文件摘要保持不变。
- 不创建、编辑、启动或归档任务；用户继续用现有 Trellis 工具完成这些操作，Dashboard 只刷新读取结果。

## R8：交付与验证

- 在独立 worktree 中交付代码、构建/测试命令及中文 README；说明环境要求、一次性安装、任意目标项目启动、参数与常见错误。
- 构建后的包不需要从目标项目加载 React、TypeScript 或开发服务器；静态资源定位与启动 cwd 无关。
- 使用临时合成 fixture 做正常/异常/安全测试；对用户给出的真实样例仅做只读冒烟，不执行其脚本或业务代码。
- 验证类型检查、构建、自动化测试、npm 打包/安装后命令启动，以及浏览器核心交互；未执行/失败/阻塞不能标记通过。
- 用长目录与长文档分别验证弹层、规范库和工作记录：桌面/移动端正文视窗尺寸、定向滚轮、边界滚动隔离、固定头部和工具栏、移动目录操作、内部锚点及刷新保持位置。用可视容器的实际尺寸和滚动量断言，不仅截取静态截图。
- 用多状态、多列长任务集合验证任务面板：整体不溢出视口、紧凑工具和统计、各列滚动隔离、固定列头、表格数据区与粘性表头、窄屏看板横向浏览和完整筛选，以及相同视图自动刷新保持位置；A4/A6 的阅读布局阈值不得回退。
- 全部最终验收项由独立只读 Verifier 核对；由用户接受最终结果。
- 参考 Trellis 的文件语义但不复制其 AGPL 实现或业务资料；保留来源说明，不假定有 npm 发布权限。

## 本 capability 的非目标

远程服务、登录权限体系、跨项目集中扫描、AI 执行、任意 shell、自动 Git 提交/推送/PR、npm 发布、替代官方 Trellis CLI、根据文档自动评估代码质量，以及任何任务写操作。
